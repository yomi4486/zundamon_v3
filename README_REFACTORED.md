# ずんだもんボット v3 - リファクタリング版

このプロジェクトは、Discordボット「ずんだもん」のコードを機能ごとに分割して、より保守しやすい構造にリファクタリングしたものです。

## ファイル構造

### 新しい構造
```
zundamon_v3/
├── main.py              # メインアプリケーション（Discordクライアント、イベントハンドラー）
├── config.py            # 設定・環境変数管理
├── text_processor.py    # テキスト処理機能（辞書変換、英語からカタカナ変換など）
├── voice_synthesis.py   # 音声合成・再生機能
├── ui_components.py     # Discord UI コンポーネント（ボタン、モーダル）
├── commands.py          # Discord スラッシュコマンド
├── index.py             # 元のファイル（バックアップ）
└── ... (その他のファイル)
```

### 各モジュールの役割

#### `config.py`
- 環境変数の読み込み
- ログ設定
- グローバル変数の定義
- 設定値の管理

#### `text_processor.py`
- テキストの整形処理
- 英語からカタカナへの変換
- 辞書変換機能
- URL、メンション、絵文字の処理

#### `voice_synthesis.py`
- VOICEVOX APIを使用した音声合成
- 音声キューの管理
- 音声再生機能

#### `ui_components.py`
- Discord UI コンポーネントの定義
- リマインダーモーダル
- 問題報告モーダル
- カスタムビュー

#### `commands.py`
- すべてのDiscordスラッシュコマンド
- コマンドの実装
- インタラクション処理

#### `main.py`
- Discordクライアントの初期化
- イベントハンドラー（メッセージ、ボイス状態変更など）
- メインループ（リマインダー処理）
- アプリケーションの起動

## 使用方法

### 起動方法
```bash
python main.py
```

### アップデート通知
```bash
python main.py update
```

## 主な改善点

1. **モジュール化**: 機能ごとにファイルを分割し、コードの見通しを改善
2. **責任の分離**: 各モジュールが明確な責任を持つように設計
3. **保守性の向上**: 特定の機能を修正する際に、該当するファイルのみを編集
4. **再利用性**: 各モジュールを他のプロジェクトでも再利用可能
5. **テスト容易性**: 各機能を独立してテストできる構造

## 移行ガイド

元の`index.py`から新しい構造への移行：

1. 環境変数とログ設定 → `config.py`
2. テキスト処理関数 → `text_processor.py`
3. 音声合成・再生関数 → `voice_synthesis.py`
4. UI コンポーネント → `ui_components.py`
5. スラッシュコマンド → `commands.py`
6. メイン処理 → `main.py`

## 注意事項

- 元の`index.py`はバックアップとして残しています
- 新しい構造では、グローバル変数の初期化が`main.py`で行われます
- 各モジュール間の依存関係は明確に定義されています
- 既存の設定ファイル（`.env`、辞書ファイルなど）はそのまま使用可能です
